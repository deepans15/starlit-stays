# Starlit Stays

A cozy hotel-building game you play in the browser: build rooms, decorate them and look after your guests.

Starlit Stays is an original, non-profit fan project inspired by classic hotel sims. All names, art and code are original. It is not affiliated with Electronic Arts or Playfish.

- `index.html`: the game
- `art/`: original artwork (SVG), `art/manifest.js` and `art/items.js`
